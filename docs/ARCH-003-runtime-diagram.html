One node's wiring, in full

Every node in the cluster — control-plane or compute, since ARCH-002 §01 puts them on identical Pi 5 hardware — is wired identically to its own boot processor. This is that wiring, once, in detail; §02 shows how all six repeat it into one fabric.

02

Cluster fabric — six boards, one switch

Figure 1's wiring repeats six times — 3 control-plane, 3 compute — with every node's Ethernet port landing on the same flat 1GbE segment. Nothing here is asymmetric at the network layer; role is entirely a software distinction (§03).
